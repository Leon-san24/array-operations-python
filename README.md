# 🧮 Python List Operations Project

This project demonstrates basic operations on number lists (`arrays`) using Python. It includes custom algorithms for analyzing and sorting lists, as well as visual representations like flowcharts and structured diagrams.

## 🔢 Sample List Used

```python
zahlen = [4, 23, 8, 13, 7, 9, 42, 11, 6, 80, 3]
```

> The code is designed to work with any list of numbers, not just the example above.

## 🧠 Project Tasks

Each task is handled by a different group:

1. **Find the smallest number in a list**
2. **Find the largest number in a list**
3. **Calculate the sum of all values**
4. **Compute the average (mean)**
5. **Determine the median**  
   - List must be sorted  
   - Built-in `sort()` method **is allowed** here
6. **Implement a custom sorting algorithm**  
   - No built-in sorting methods allowed

## 🧾 Additional Deliverables

- 📊 Flowchart for tasks **1, 4, and 5**
- 📐 Structogram for task **6**
- 🗣️ Plain-language explanation of the custom sorting algorithm
